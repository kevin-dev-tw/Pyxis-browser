Service notes

Honest edges.

unsigned
SmartScreen will warn. Unsigned build — right-click → properties → unblock. A code-signing cert costs real money; this is a personal project.
extensions
None. WebView2 can't run Chrome extensions. Ad blocking and clean links are built in to cover the common cases.
engine
Chromium via WebView2. Same rendering engine as Edge — not a full Chromium fork.
beta
One developer, one machine. Bugs get fixed; report them on GitHub.
FAQ

Straight answers.

Is it free?

Yes — it's a personal project, source available on GitHub. Download, run the installer, done.

Where does my data go?

JSON files in %LocalAppData%\Pyxis. Nothing is sent anywhere — there is no account and no sync service to send it to.

Is it based on Chrome?

Same engine — Chromium via WebView2, so pages render like Edge. The shell is our own .NET 8 app, not a Chromium fork.

Does it update itself?

It checks the release channel on startup and offers the new installer — it never installs anything without your click.

Can I set it as default?

Yes — the welcome screen links straight into Windows default-apps settings, and the installer registers Pyxis as a browser candidate.
