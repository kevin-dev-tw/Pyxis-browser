Info desk

Is it free?

Yes — it's a personal project, source available on GitHub. Download, run the installer, done.

Where does my data go?

Bookmarks, history and settings are JSON files in %LocalAppData%\Pyxis. Readable, deletable, yours. Nothing is sent anywhere — there is no account and no sync service to send it to.

Is it based on Chrome?

Same engine — Chromium via WebView2, so pages render like Edge. The shell is our own .NET 8 app, not a Chromium fork.

What about the AI sidebar?

Optional and off by default — bring your own Groq API key. No key means it never runs and never talks to anyone.

Does it update itself?

It checks the release channel on startup and offers to download the new installer — it never installs anything without your click.
