Features

Built like a tool, not a feed.

Everything a browser needs, nothing it doesn't. Every surface stays quiet so the web stays loud.

≡

Adaptive tabs

Chrome-style compression: tabs shrink smoothly from 220px down to icon-only as you open more. Overflow scrolls horizontally.

◫

Split view

Two pages side by side in one tab with an active-pane focus ring. Perfect for docs on the left, work on the right.

⚜

Shields built in

EasyList and EasyPrivacy filtering at the network layer — ads and trackers never reach the page. Toggle anytime.

◑

Dark & light

A real theme system: chrome, internal pages and web prefers-color-scheme all switch together.

◉

Incognito tabs

Isolated session profile marked in violet. Nothing persists — history, cookies and cache vanish on close.

⌘

Keyboard-first

Ctrl+\ split, Ctrl+H history, Ctrl+J downloads, Ctrl+Shift+B bookmarks bar. Keep typing.

↗

Internal pages

pyxis://newtab, pyxis://history and pyxis://settings render offline, instantly.

☁

Remote start page

The new-tab page can sync from a deployed URL — update the site, every install picks it up on next launch.

↓

Chromium inside

WebView2 runtime: the same engine as Edge, packaged in ~1 MB of your own code. No Electron shell, no bloat.
