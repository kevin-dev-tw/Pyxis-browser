Security & privacy

WHAT WE DO — AND WHAT WE DON'T HIDE

IN THE BROWSER

+
Zero telemetry. Nothing in the code phones home — there is no analytics, reporting or vendor cloud anywhere.
+
Local-first storage. Bookmarks, history, shortcuts, chats and settings are plain JSON in %LocalAppData%\Pyxis — readable and deletable by you.
+
Tracker blocking. EasyList + EasyPrivacy filters cut third-party trackers at the network layer, plus cosmetic hiding.
+
Clean links. Copy strips utm_*, fbclid, gclid and other tracking params before sharing.
+
One-key wipe. Clear site data removes cookies, site storage, HTTP cache, browsing and download history — behind a confirm dialog.
+
Real incognito. Incognito tabs use a separate in-memory WebView2 profile — nothing is persisted, ever.

KNOWN EDGES

−
Default search is Google. Queries go to Google unless you change engines — the engine sees your searches.
−
SmartScreen. WebView2's safe-browsing check may report URLs to Microsoft; it can be disabled per profile.
−
Start-page weather. The weather card calls wttr.in, exposing your public IP to that service.
−
No anonymity layer. Your ISP sees your traffic — Pyxis doesn't hide you, it doesn't hide from you.

Questions

FAQ
Is Pyxis real Chromium?

Pyxis renders with the same Chromium engine as Microsoft Edge via WebView2 — Blink layout, V8 JavaScript, full HTML5. It's not a fork of Google Chrome, so Chrome UI features and extensions aren't carried over.

Does Pyxis send my data anywhere?

No. There is no account, no sync service, no analytics. Bookmarks, history, shortcuts and settings are JSON files in %LocalAppData%\Pyxis — readable and deletable by you at any time.

Can I install Chrome extensions?

No — WebView2 doesn't support Chrome extensions. Built-in replacements cover the common cases: ad blocking, screenshots, clean-link copying and incognito are already inside.

Is it Windows-only?

Yes. The shell is WPF (.NET 8) and WebView2 is a Windows technology. macOS or Linux support would require a different stack entirely.

Is it free?

Yes — it's a personal project, source available on GitHub. Download the release, run the exe, done.
