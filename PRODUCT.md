# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Privacy-conscious Windows power users and indie-tool enthusiasts; bilingual audience (English + Traditional Chinese, Taiwan developer community reachable via Dcard/IG).

## Product Purpose

Pyxis is a local-first Chromium browser for Windows (WebView2/.NET 8). Free, no account, no sync, no telemetry — bookmarks, history and settings live as readable JSON in %LocalAppData%. Success = downloads of PyxisSetup.exe and return visits to the site.

## Positioning

A browser whose data provably never leaves the disk — the local-first claim competitors (Brave/Vivaldi/Arc) can copy in marketing but not in mechanism: Pyxis has no sync service, no account system, and its data files are human-readable.

## Operating Context

Signed-out Windows users; the installer is unsigned, so the page must pre-empt SmartScreen friction (right-click → unblock). Distribution is a direct /download proxied asset plus GitHub Releases; auto-update checks the same evergreen release. Public voice is bilingual, calm, engineering-toned.

## Capabilities and Constraints

Real, shippable facts for the page: adaptive tab strip, split view (Ctrl+\), EasyList+EasyPrivacy ad blocking, Zen mode (Ctrl+Shift+Z), screenshot to PNG, clean-link copy, clear-site-data, bookmarks with folders + manager, history, downloads, dark/light themes, en/zh-TW UI, F12 devtools, Ctrl+P print, session restore opt-in, first-run welcome, built-in Groq AI sidebar (bring-your-own-key). Constraints: unsigned build warning must stay visible near the download CTA; no extension support; WebView2 engine (honest wording: "Chromium engine via WebView2", not "full Chromium").

## Brand Commitments

Name: Pyxis. Accent: Signal Ember #E0703A (the one accent, "ember — quiet but warm"). Voice: cold, precise, honest — no hype words ("next-gen", "seamless", "elevate"), no emoji. Logo: flame-in-circle mark in logo_2/. Typography on web: Segoe UI Variable for UI, JetBrains Mono for labels/metrics. Known-edges honesty is a brand trait (the page states what it can't do).

## Evidence on Hand

screenshot.png (real start-page UI), PyxisSetup.exe download asset, brand.html + brand.pdf, GitHub repo. No testimonials, press, user counts, or benchmarks — do not fabricate.

## Product Principles

1. Local-first honesty — claims stay verifiable, including weaknesses.
2. One accent, quiet warmth — never gradient-heavy or neon.
3. Bilingual and engineering-literate, never marketing-voiced.
4. Friction honesty beats conversion tricks (unsigned warning stays).
